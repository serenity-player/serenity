# Screenshots

Screenshots can't be generated automatically, so the README has them commented out. To publish them:

1. Run the app (light *and* dark mode, if you like) and capture these screens with a phone or emulator:
   - `now-playing.png`: Now Playing with a colourful album cover
   - `library.png`: Library, Playlists tab
   - `search.png`: Search results
   - `queue.png`: the queue sheet
   - `tablet.png`: the two-pane Now Playing on a tablet or unfolded foldable (optional)
2. Save them in this folder (about 1080 px wide is plenty; compress them with `oxipng` or an online tool).
3. In `README.md`, remove the `<!--` and `-->` around the *Screenshots* section.
